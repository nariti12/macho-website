# IP使用ルール（技術・ビジュアル正本）

## 維持する特徴

- 顔は常に`face2`。成長で顔、髪、表情、頭部サイズを変えない。
- 成長するのは首から下のボディだけ。
- Lv1は細身、Lv50はブランド代表形態、Lv100は異次元の最終形態。
- 肌色、黒いボトム、正面向き、全身構図を基本シルエットとする。

## 禁止

- 顔と身体を別々に再配置して首位置を調整すること。
- 顔だけの拡大縮小、横伸ばし、回転、左右反転。
- ポーズごとにAIで同一人物を再生成し、顔や体格をドリフトさせること。
- WebトップでLv1〜100を一括プリロードすること。
- 元画像と同じファイル名で視覚変更を上書きし、キャッシュ事故を起こすこと。

## 許可する演出

- 完成キャラクター全体への微細な呼吸、上下動、影の変化。
- 同じ表示矩形内での進化クロスフェード。
- 背景、光、パーティクル、UIによる世界観演出。
